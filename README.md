# Implementasi Dependency ILP: RAW, WAR, dan WAW

## Deskripsi
Proyek ini dibuat untuk memenuhi tugas kelompok mengenai
Instruction-Level Parallelism (ILP).

## Tujuan
Mengimplementasikan dan memahami tiga jenis dependency
antarinstruksi.

## Jenis Dependency

### 1. RAW (Read After Write)
Terjadi ketika instruksi membaca data yang ditulis
oleh instruksi sebelumnya.

### 2. WAR (Write After Read)
Terjadi ketika instruksi menulis register yang sebelumnya
dibaca oleh instruksi terdahulu.

### 3. WAW (Write After Write)
Terjadi ketika dua instruksi menulis register yang sama.
